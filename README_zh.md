# 吾有一术：新秩序

Wenyan Addon (吾有一术：新秩序) 是“吾有一术”生态的实验性附属模组。
它的定位是在 [Wenyan Programming](https://github.com/gyxx-xc/WenyanNature) 本体之上，测试和提供新颖、特别的功能扩展。


稳定的功能会被提升至 [Wenyan Programming](https://github.com/gyxx-xc/WenyanNature) 作为本体的一部分。

> [!NOTE]
> 吾有一术：新秩序的定位是快速测试新功能，包含不稳定的代码和新特性。功能后续可能加入到本体之中，也可能随时被删除，修改。

## 特色

- **快速迭代**：实验性功能，尚未稳定的新机制会在此得到测试和开发。
- **突破本体限制**：允许尝试 [Wenyan Programming](https://github.com/gyxx-xc/WenyanNature) 本体中不便直接实现的交互和玩法。
- **更有特色的内容实验**：可以承载更偏实验性、主题性或独立模块化的内容，例如内置的 Pong 模块。

## 稳定性说明

Wenyan Addon 不保证代码稳定性。

本仓库可能包含实验代码、临时 API、功能迁移，以及“又不是不能用”的功能。

> [!WARNING]
> 使用时请预期不同版本之间互不兼容，可能需要调整存档、配置、脚本或代码。


## 开发

目标环境：

- Minecraft `26.1.2`
- NeoForge `26.1.2.71`
- Java `25`

常用命令：

```bash
./gradlew compileJava
./gradlew runData
./gradlew build
```
